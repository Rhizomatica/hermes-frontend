# Agent Notes

## Branches

- Before starting any work, always check whether it belongs on a new branch. Never assume the currently checked-out branch is the right place.
- Create new work branches from `origin/main` unless the user says otherwise.
- Do not leave new commits on an existing feature branch unintentionally; move them to the correct branch and restore the original.

## Commits

- Divide work into small, focused commits.
- Do not put many unrelated files in a single commit; keep each commit reviewable and scoped to one logical change.
